Questions

 

Windows says “Windows protected your PC”. Is it safe?

Windows shows this for new apps until their publisher certificate builds a reputation. Click More info, then Run anyway. A signed installer is on the way and will remove this message.

Can I use my Claude Pro or ChatGPT Plus subscription?

No. Those subscriptions only work in Claude’s and OpenAI’s own apps. Voice Agent uses an API key, which you create at console.anthropic.com or platform.openai.com and pay for by usage.

Where is my data stored?

Your conversations and settings are saved on your own computer. Your API key is encrypted with your operating system’s secure storage and is only sent to the AI provider you chose.

Is there a Mac version?

Yes, it’s coming soon. The Windows version is available today.

How do updates work?

The app checks for new versions in the background, downloads them and shows a “Restart to update” button. You can also check from Settings.
