# Voice_Updates

Public downloads and auto-updates for **Voice Agent**.

- **Website:** https://voiceagent-download.lovable.app (built in Lovable). `docs/` keeps a backup copy of the page.
- **Releases:** each version's Windows installer (`Voice-Agent-Setup.exe`) and the `latest.yml` file
  the app reads to update itself. Releases are published automatically by the build pipeline in
  the Voice_Code repository; don't upload files here by hand.

Direct download of the newest version:
https://github.com/Musmanai/Voice_Updates/releases/latest/download/Voice-Agent-Setup.exe
